#Urban Crime Risk Prediction Using Machine Learning
###A London Case Study

##📌 Project Overview

This project presents a comparative machine learning analysis of urban crime risk patterns in London using large-scale public data. The study evaluates supervised learning models to support preventive, ethical crime risk awareness, with a particular focus on student populations—especially international students—who may lack local knowledge of high-risk areas and times.

Rather than reactive safety systems, this research explores how data-driven prediction can complement existing university safety tools by enabling earlier risk awareness.

##✨ Key Features
-Logistic Regression, Random Forest, and Gradient Boosting <br/>
-Borough-level, temporal crime risk modelling using official London crime data <br/>
-Focus on prevention over reaction, avoiding individual profiling <br/>
-Model explainability using SHAP and LIME for transparent decision-making <br/>
-Ethical design aligned with responsible AI and public safety principles <br/>

##🧠 Technologies & Tools
-Python (Pandas, NumPy, scikit-learn, XGBoost) <br/>
-Google Colab for reproducible cloud-based analysis <br/>
-SHAP & LIME for model interpretability <br/>
-Matplotlib & Seaborn for data visualisation <br/>
-Git/GitHub for version control and documentation <br/>

##🧩 Data Sources
-Metropolitan Police Service open crime datasets (borough & monthly level) <br/>
-Public urban and temporal context data (seasonality, time-based indicators) <br/>
-Peer-reviewed academic literature on crime prediction and ethical ML <br/>

##💡 Key Learnings
-Ensemble models achieve strong predictive performance, but interpretability is essential for ethical use <br/>
-Crime data reflects reporting and structural biases that must be critically addressed <br/>
-Spatial–temporal aggregation enables safer, non-intrusive predictive analytics <br/>
-Ethical framing significantly improves real-world applicability of ML in public contexts <br/>

##🎯 Research Focus

While the crime data represent the general urban environment, this project frames student populations—particularly international students—as a key beneficiary group for evaluating the practical and ethical applicability of crime risk prediction models.
